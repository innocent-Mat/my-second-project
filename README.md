 👟 Shoes E-Commerce Website

A modern and responsive shoes e-commerce web application that allows users to browse, search, and purchase shoes online.  
This project demonstrates full-stack web development skills, including UI design, backend logic, and database integration.

 🚀 Features

    👤 User Features
- User registration and login
- Browse shoes by category, brand, or price
- Search for shoes
- View product details (images, price, description, size)
- Add shoes to cart
- Checkout and place orders

      🛠️ Admin Features
- Add, update, and delete shoe products
- Manage categories
- View customer orders
- Update order status

      🧰 Technologies Used

- Frontend
  - HTML5
  - CSS3
  - JavaScript
  - Bootstrap

- Backend
  - PHP

- Database
  - MySQL

- Server
  - XAMPP
